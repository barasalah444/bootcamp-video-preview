# bootcamp-video-preview

Welcome to video-preview! This is a responsive and interactive video preview web page built to practice and demonstrate core web development concepts.

## About the Project
The goal of this project is to create a clean, video-platform-like interface (similar to YouTube) with an interactive feature that improves user experience using basic JavaScript.

### Implemented Features:
* **Structured Layout (HTML5):** Divided the page cleanly into a two-column layout: the main video player on the left and the "Up Next" recommended videos list on the right.
* **Styling & Alignment (CSS3):** Used Flexbox for layout alignment. Set the video player to exact dimensions (720px by 400px) to match the wireframe perfectly, complete with smooth rounded corners and a cinematic black background.
* **Smart Interaction (JavaScript):** Implemented a smooth hover effect. The video automatically plays when the user hovers over it (onmouseover) and pauses immediately when the mouse leaves (onmouseout).

---

## Technologies Used
* **HTML5** (For semantic structure and media elements)
* **CSS3** (For styling, colors, layout, and Flexbox)
* **JavaScript** (For controlling video playback via user interaction)

---

## How to Run the Project Locally

This project is completely client-side and doesn't require any local servers or complex setup. To run it, follow these simple steps:

1. **Download the Project:** Clone this repository or download the source files directly to your local machine.
2. **Check Assets:** Ensure that the video file and any asset icons are placed in the same project directory alongside the code files.
3. **Launch:** Double-click the `index.html` file to open the project directly in any modern web browser (e.g., Google Chrome or Microsoft Edge).
4. **Test the Feature:** Hover your mouse cursor over the main video player to see it play automatically, and move your mouse away to watch it pause!
